# 项目弹药库示例（Project Library Example）

> **用途**：存放真实经历的事实层素材（背景 / 行动 / 量化结果 / 时间归属）。
> 复制本文件为 `references/project-library.md`，替换为你的真实项目。
> ⚠️ 本示例为虚构内容，仅演示结构，严禁直接使用。
>
> **使用规则**：
> 1. 弹药库只提供**原始素材**，不提供预制简历话术——放入简历的每一条都必须经写作层（STAR / 行为链条 / 证据三件套）按目标 JD **重新组织措辞**，不得照抄。
> 2. 写简历时从中选 3-4 个与 JD 最相关的项目组合，**选材须先给用户过目确认**。
> 3. **时间线铁律**：项目归属公司/时间段以本文件标注为准，不得改动；各公司段固定保留哪些项目由 `config/profile.yml` 的 `project_grouping` 声明。
> 4. **适用边界**：标"限特定岗位"的项目只能在对应岗位类型的 JD 下使用（防止组合错乱、时间线穿帮）。
> 5. 所有数据均来自真实经历，禁止虚构、禁止张冠李戴（A 项目的成果不得写成 B 项目的）。
> 6. 新增/修改项目时直接编辑本文件对应条目，保持相同结构。

## 维护说明

- **加项目**：在「索引摘要」表加一行 + 按上述结构追加详情节。
- **改项目**：直接编辑对应详情节，保持结构。
- **删除项目**：索引表与详情节同步删除。
- **时间线铁律**：项目归属公司/时间段以本文件为准，不改动；固定保留/增量挑选由 `config/profile.yml` 的 `project_grouping` 声明。
