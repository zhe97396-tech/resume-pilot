# 面试问题库（按岗位类型分层）

> **用途**：累积真实面试问题，形成"**按岗位类型分层的高频题**"，反哺面试准备的出题与追问预判。全局单文件累积（跨所有 JD）。
> **核心约束**：高频**按岗位类型隔离**——电商的高频题不得直接套用到工具类岗位。
> 与 `interview-story-bank.md`（故事沉淀）、`interview-prep-framework.md`（准备主流程）配合。

## §1 核心原则

1. **按岗位类型分层**：每个问题记录在它出现的岗位类型下；"高频"指**该类型内的高频**，非全局高频。
2. **同类型才复用**：下次 JD 属同类型 → 该类型高频题**必覆盖**；不同类型 → 仅供参考，不自动带出。
3. **混合形式**：高频题（该类型内命中 ≥2 次）给**完整逐字稿**；低频题给**要点式思路**。
4. **事实以用户为准**：改进版答案保留用户真实事实，只重构表达顺序；**不添加用户没说过的内容**（发现弹药库有亮点未讲到，先问用户能否讲）。
5. **回答记录 ≠ 标准答案**：用户临场回答是**评估样本**，不是入库的范本。

## §2 岗位类型定义

从 JD + Phase 2.5 选材结果判定；**术语与弹药库「适用岗位」标签保持一致**；一个 JD 可同时属多类型。

| 大类 | 类型标签 |
|------|---------|
| 产品方向 | 商业化 / 增长 / 策略 / 平台 / 用户产品 / 创新0-1 |
| 形态 | B端/SaaS / AI / 工具 / 电商 / 内容 |
| 行业 | 行业-教育 / 行业-医疗 / 行业-金融 / 旅游 / 内容社区 / 广告 |

**类型判定示例**：
- "某电商平台 电商产品经理" → `电商` + `商业化` + `平台`
- "某工具 App 产品经理" → `工具` + `增长`

## §3 问题记录格式

```markdown
### Q: {面试官原题}
- **岗位类型**：{类型标签}
- **问题类型**：{项目深挖 / 个人动机 / 情景题 / 数据能力 / 协作…}
- **命中记录**：{公司·岗位}（{日期}）｜{公司·岗位}（{日期}）… → 该类型内共 N 次
- **我的现场回答**：{如实记录，非标准答案}
- **评估**：{见 §6 四维度}
- **改进**：{高频→逐字稿；低频→要点式}
- **来源**：弹药库 #{N}
```

**高频判定**：同一问题类型在**同一岗位类型**下命中 ≥2 次。

### 【通用题】（跨类型共用，每次必覆盖）

个人动机类问题不受岗位类型限制，始终纳入准备：

| 问题类型 | 常见问法 |
|---------|---------|
| 离职原因 | "为什么从上家离职？" |
| 职业状态 | "这一年为什么没上班？" |
| 公司选择 | "为什么选择我们公司？" |
| 职业规划 | "你的职业规划是什么？" |
| 优劣势 | "你的优势/劣势是什么？" |
| 薪资 | "期望薪资是多少？" |
| 反问 | "你有什么想问的？" |

> 通用题的准备方法见 `interview-personal-qa.md`。

## §5 用法（两个时机）

### 时机 1：面试准备时（反哺出题）

```
Step 1 判定本次 JD 的岗位类型（可多类型）
Step 2 取【同类型】高频题 + 【通用题】 → 必覆盖
Step 3 其他类型的高频题 → 仅供参考，不自动带出
Step 4 该类型的盲区题 → 本次准备必须补上
```

**灵活变通**：JD 类型与库内类型不完全匹配时，按"**最接近类型 + 通用题**"组合，不硬套（如纯工具岗不套电商高频的"转化漏斗"题）。

### 时机 2：面试复盘时（收集）

用户提供：**面试官的问题**（必）+ 自己的临场回答（有则更佳）+ 自评（可选）。

## §6 复盘处理流程

| 步骤 | 动作 |
|------|------|
| ① 归档 | 按「岗位类型 + 问题类型」归入 §4；命中记录追加 |
| ② 评估 | 按下方四维度对照弹药库评估现场回答 |
| ③ 改进 | 保留事实 → 重构表达（高频给逐字稿、低频给要点）；有事实缺口先问用户 |
| ④ 反哺 | 更新该类型高频/盲区；把暴露的缺口写进下次准备的出题清单 |

**评估四维度**：

| 维度 | 看什么 |
|------|--------|
| 事实准确 | 与弹药库对照，有无夸大/记错 |
| 亮点遗漏 | 弹药库有、但没讲到的数据/动作/约束 |
| 结构清晰 | 有无跑题、有无"问题→方法→验证→结果"骨架 |
| 踩雷检测 | 是否抱怨前公司、过度谦虚、暴露短板 |

## §7 盲区题

回答不上或完全没准备到的题 → 记入对应岗位类型的「盲区题」→ **下次准备必须补**。盲区题是出题逻辑改进的最直接来源。

## §8 维护说明

- **加问题**：按 §3 格式追加到对应岗位类型的 §4 下。
- **升级高频**：同类型命中达 2 次 → 移入「高频题」并补逐字稿。
- **事实冲突**：与弹药库不一致时**以弹药库为准**。
- **类型判断不确定**：按 §2 判定；跨类型时可同时归入多类型。
