# 简历优化策略指南

本文档涵盖简历定制过程中的三个高阶策略：证据重排、模块优先级、AI三版本压缩法。

## 一、证据重排策略

### 核逻辑

内容梳理完成后，不要直接保存。要从招聘方阅读视角重新排列内容顺序，把核心优势前置。

### 基础规则

工作经历统一采用**倒序排列**（最近的工作在最前），这是通用规范，不可打乱。

在倒序基础上，优化**单段工作内部**的内容排序：严格按照JD的关键词顺序，重新排列工作实绩。JD重点强调的能力，对应的相关经历往前放。

### 排序操作步骤

1. 提取JD中前5-6条核心要求，按JD中的出现顺序编号（JD排在前面的=权重更高）
2. 对当前工作经历的每个bullet，标注对应的JD要求编号
3. 按JD编号顺序重排bullet（编号小的在前）
4. 无对应JD要求的bullet，移至该段经历末尾或删除

### 项目板块补救技巧

当最新工作与目标岗位相关性不高，但过往某段经历高度匹配时：

- 不调整工作时间顺序（保持倒序）
- 新增独立的**「项目经历」板块**
- 项目板块**不受时间顺序限制**，完全按岗位匹配度排序
- 最贴合JD要求的项目放最前面
- 以此弥补近期经历不匹配的短板

**示例**：
```
工作经历（倒序）
  公司A（2022-2024，与目标岗位弱相关）→ 精简为1-2个bullet
  公司B（2019-2022，中等相关）→ 2个bullet

项目经历（按JD匹配度排序，不受时间限制）
  项目X（2020，高度匹配JD核心要求）→ 3个完整STAR bullet
  项目Y（2021，匹配JD第二要求）→ 2个STAR bullet
```

## 二、模块优先级策略

### 学历模块定位

| 情况 | 策略 | 原因 |
|------|------|------|
| 985/211/海归名校 | 学历模块前置（简历开头，核心优势之后） | 名校背景是加分项，尽早展示 |
| 学历普通但经历强 | 学历模块后置（简历末尾，技能之前） | 避免学历成为第一印象的短板 |
| 应届生/校招 | 学历模块前置 | 经历少，学历是核心卖点 |
| 跨行业转行 | 学历模块后置 | 突出可迁移经历，弱化学历背景差异 |

### 技能模块避坑

**以下内容绝不可放在简历靠前位置**：

- 基础办公软件（"熟练使用PPT、Word、Excel"）
- 基础语言能力（"英语四级""普通话标准"）
- 兴趣爱好（"喜欢阅读、旅行、摄影"）
- 过于宽泛的软技能（"沟通能力强、学习能力强"）

这些内容放在前面会让HR判定求职者不会梳理工作重点，增加淘汰风险。如必须写，放在简历最末尾，一行带过。

### 模块推荐排序

根据用户情况动态调整模块顺序：

**经历驱动型**（经历强、学历普通）：
```
基本信息 → 求职意向 → 核心优势 → 工作经历 → 项目经历 → 技能清单 → 教育背景
```

**学历驱动型**（名校应届/校招）：
```
基本信息 → 求职意向 → 教育背景 → 核心优势 → 实习/项目经历 → 技能清单
```

**转行/跨行型**（经历与目标岗位非直接对口）：
```
基本信息 → 求职意向 → 核心优势（强调可迁移能力） → 项目经历（按匹配度排序） → 工作经历 → 技能清单 → 教育背景
```

## 三、AI三版本压缩法

### 适用场景

简历内容梳理、排序完成后，最后一步优化语言、精简文字时使用。

### 操作方法

将完整简历 + 目标JD同时提供，设定明确字数限制，生成三个版本：

| 版本 | 特征 | 用途 |
|------|------|------|
| 极致精简版 | 每段经历1-2个bullet，单条不超1行，只保留最强数据 | 确认删减下限——哪些内容绝对不能丢 |
| 原版完整保留 | 保持原始详略不做删减 | 确认信息上限——哪些内容是冗余可删的 |
| 适中优化版 | 每段经历2-3个bullet，单条1-2行，保留核心数据但剔除冗余表述 | 最终交付版的基础 |

### 微调方法

1. 对比极致版与原版，识别"删了会丢失核心信息"的内容（这些必须保留）
2. 对比原版与适中版，识别"删了不影响理解"的内容（这些可以删）
3. 在适中版基础上，逐条微调：
   - 检查每个bullet是否含数据（无数据的补充或删除）
   - 检查是否有重复表述（合并同类项）
   - 检查是否有过长的过程描述（精简为结果导向）
   - 检查是否有"负责式"表述（改为动词开头的成果表述）

### 压缩优先级

当需要精简时，按以下顺序删减（从前到后，越前面越先删）：

1. 删无关内容：与JD无关的职责描述
2. 删过程细节：只保留行动方向和结果，删掉具体步骤
3. 删弱数据：多个数据点时保留最强的，删掉次要的
4. 合并同类：同一类型的经历合并为一条
5. 精简措辞：去掉" successfully""有效地"等修饰词，数据本身就是证明

### 字数参考

| 经验年限 | 简历总字数参考 | 每段经历bullet数 |
|---------|-------------|----------------|
| 1-3年 | 600-800字 | 2-3个 |
| 3-5年 | 800-1200字 | 2-3个 |
| 5-10年 | 1200-1800字 | 3-4个 |
| 10年+ | 1500-2000字 | 3-4个 |

超出参考字数时，优先精简与JD弱相关的内容。
