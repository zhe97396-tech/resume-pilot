# 面试攻略（策略层）

> 本文件是面试准备的**策略层**：把 JD 语言翻译成你的经验语言、判断招聘背景、准备反问、面试心态与前检查。
> 与 `interview-self-intro.md`、`interview-qa-bank.md`、`interview-personal-qa.md`、`interview-prep-framework.md` 配合。

## §1 JD 关键词翻译表

**目的**：面试时快速建立"JD 要求 ↔ 我的经验"的匹配认知，避免答非所问。

**生成方式**：取 JD 拆解出的关键词，逐个匹配弹药库项目，标注匹配类型与证据：

| JD关键词 | 优先级 | 你的经验表述 | 匹配类型 | 证据项目 | 话术建议 |
|---------|--------|-------------|---------|---------|---------|
| （逐条填写） | | | | | |

**匹配类型**：`exact`（完全一致）／`synonym`（同义）／`partial`（部分相关）／`gap`（无匹配，需 Gap 应对）。

**匹配类型不得夸大**（否则追问必露）：
- 指标口径不同的不得标 exact：如"线索转化率"≠"支付转化率/复购率"，应为 partial
- 只命中上位概念的不得标 exact（如"商业化"≠"交易链路"）
- 拿不准时取更保守的一档

**翻译技巧**（JD 表述背后的真实关切）：

| JD 表述 | 面试官真正关心的 | 回答方向 |
|--------|----------------|---------|
| 项目推进 | 能否拆解任务、推动协作、控节点 | "拆成关键节点 + 建立追踪机制" |
| 跨部门沟通 | 能否对齐目标、减少摩擦 | "建对齐机制，达成共识" |
| 抗压能力 | 事情多变化快，怕扛不住 | "同时推进 X 个项目，靠优先级管理" |
| 自驱力强 | 没人带，要自己找方向 | "在模糊场景中自定方向与节奏" |
| 数据驱动 | 是否用数据而非感觉做决策 | "看漏斗定位问题，AB 验证" |

## §2 招聘背景分析

判断岗位类型，调整面试策略：

| 背景类型 | 特征 | 面试策略 |
|---------|------|---------|
| 新增岗位 | JD 出现"从0到1/搭建/新业务" | 突出 0-1 能力、方法沉淀 |
| 替补岗位 | 有人离职 | 突出稳定性、快速上手 |
| 急招岗位 | JD 出现"尽快/紧急/立刻到岗" | 突出即战力、相关经验、可到岗时间 |
| 储备岗位 | JD 出现"培养/储备/潜力" | 突出学习能力、潜力、文化匹配 |
| 待确认 | 无明显措辞 | 面试时反问确认 |

**反问确认话术**："这个岗位是新增的还是替补的？目前最急需解决什么问题？"

## §3 反问环节

### 3.1 提问设计原则

- 展示对岗位和公司的了解（不是百度能搜到的）
- 体现专业深度（问业务逻辑而非福利待遇）
- 表达加入意愿（问入职后的事，而非为什么招人）
- 3-5 个为宜，按重要度排序

### 3.2 按面试官角色选问

> **默认要求**：不知道面试官构成时，**四个角色（HR / 直属 Leader / 交叉面试官 / 高管）均需准备**，实际按到场面次选用。

| 面试官 | 推荐数量 | 问题方向 |
|--------|---------|---------|
| HR | 1-2 | 招聘背景、团队规模、晋升机制 |
| 直属 Leader | 2-3 | 最大挑战、岗位成功标准、前三个月期望 |
| 交叉面试官 | 1-2 | 核心能力要求、协作方式 |
| 高管 | 1-2 | 战略重点、岗位在战略中的位置 |

### 3.3 按问题类型参考

| 类型 | 示例 | 适用场景 |
|------|------|---------|
| 岗位相关 | "这个岗位核心解决的业务问题是什么" | 所有场景 |
| 团队相关 | "团队目前的规模和分工是怎样的" | 关注协作模式 |
| 业务相关 | "公司目前在 XX 方面的最大挑战是什么" | 展示行业认知 |
| 发展相关 | "这个岗位过去半年的主要进展和下一步规划" | 展示加入意愿 |
| 文化相关 | "团队最近一次复盘讨论的话题是什么" | 考察文化氛围 |

### 3.4 避免问的

❌ 薪资福利（留给 HR 环节）❌ 加班情况（可间接问"团队典型节奏"）❌ 百度可查的基础信息 ❌ 过于宏观的战略空谈。

## §4 公司调研（面试用）

按目标公司调研并提炼 3-5 条**面试中可自然引用**的信息：

| 调研项 | 用途 |
|--------|------|
| 主营业务与行业地位 | 回答"为什么选我们"、展示了解 |
| 产品/业务近期动态 | 反问、展示做过功课 |
| 竞品格局 | 产品设计思考、行业洞察 |
| 面经真题（如可搜到） | 补充预测题目（标注来源） |

**约束**：调研信息必须真实可查（标注来源）；搜不到的标"未获取"，用 JD 推导兜底，不编造。

## §5 面试心态

**核心转变**：从"证明我配得上"→"展示我能解决你们什么问题"。

| 认知 | 说明 |
|------|------|
| 面试是双向选择 | 你也在评估公司 |
| 面试官关心 | "这个人好用吗？会出事吗？" |
| 不追求全能 | 展示能解决核心问题，坦诚承认不足 |

**面试前自问**：① 我这次要让对方放心什么（稳定性/专业度/解决问题）？② 我能解决这个岗位最核心的什么问题？③ 哪些经验可以直接迁移？

## §6 面试注意事项

### 6.1 着装建议

| 公司类型 | 建议 |
|---------|------|
| 互联网/创业公司 | 商务休闲（衬衫/POLO + 休闲裤） |
| 外企 | 商务正装或商务休闲 |
| 国企/事业单位 | 正装（西装 + 领带） |
| 创意/设计类 | 体现个人风格的休闲穿搭 |

### 6.2 文化匹配注意点

基于公司调研生成 2-3 条文化适配提醒：
- 公司推崇什么价值观 → 面试中如何自然体现
- 公司排斥什么 → 面试中避免说什么
- 行业特点 → 沟通中需展示什么认知

### 6.3 避坑提醒（按真实情况准备话术）

| 情况 | 准备 |
|------|------|
| 有职业空窗期 | 准备空窗期话术（见 `interview-personal-qa.md` §1.2） |
| 处于个人项目/自由职业期 | 按 `interview-personal-qa.md` §1.2 表述为能力证明 |
| 跨行业跳槽 | 准备"为什么转行"的回答 |
| 有短期任职 | 准备合理解释（不抱怨、不推诿） |
| 学历与要求有差距 | 用经历成果补位 |

## §7 面试前检查清单

**内容**：□ JD 核心诉求熟记（Top 3）□ 自我介绍已练习（目标时长内）□ 项目故事已复习 □ Gap 话术已备 □ 反问问题已备（3-5 个）

**公司**：□ 基本信息了解 □ 产品体验过 □ 近期动态了解

**后勤**：□ 简历/屏幕共享就绪 □ 提前 5-10 分钟进入
